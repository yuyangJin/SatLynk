# Case 7: 碎片碰撞预警 — 紧急计算 + 受限传播链

## 科学背景

空间碎片碰撞规避（Conjunction Assessment）。ESA 每周处理数百个碰撞告警，
当前流程依赖地面（延迟数小时到一天）。如果碰撞概率模型部署在轨，
卫星可自主决策是否机动——但精轨计算量大，纳卫星算不动。

紧急性极高：从发现碎片到最近接近点（TCA）可能只有几十分钟。

## 参数

| 属性 | 值 |
|------|---|
| 星座 | 3 det (光学监测) + 12 comp, Walker(12/3/1) 550km |
| 观测数据 | 角测量序列 + 协方差矩阵 ~500 KB |
| AI 模型 | 碰撞概率贝叶斯 ML (200M params), 400 MB 权重 |
| 推理 + MC采样 | ~5s on 1 TFLOPS |
| 结果 | 碰撞概率 + 规避/不规避决策 ~10 KB |
| Deadline | TCA - 30min = 硬限 |
| 链路 | det 2 Mbps, comp 50 Mbps |

## 验证目标

1. 在不同星座密度下，"观测→计算→决策回传"全链路响应时间
2. 对比"下传地面处理"的延迟（GS pass 平均等待 45min）
3. Deadline miss rate vs 星座密度的关系

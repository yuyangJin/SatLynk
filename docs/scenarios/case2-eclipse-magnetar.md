# Case 2: 地影穿越期瞬变响应 — 能耗约束下的磁星爆发判决

## 科学背景

磁星（Magnetar）是极强磁场的中子星，会突发释放软 γ 重复暴（SGR）。
这类爆发持续 0.1-1 秒，峰值流量可达普通 GRB 的 100 倍但极短暂。
在轨实时判决的意义：**< 5 秒内判断是 SGR 还是噪声**，若确认则立即
触发全星座联合观测模式，否则瞬变数据窗口过去后无法追溯。

**关键冲突**：磁星爆发不挑时间。当爆发发生时，探测星和/或计算星
可能正在地影中（占轨道周期 ~33%），电池纯放电。如果调度器不考虑
能量状态，会把任务派给电量不足的星 → 触发 SAFE_MODE → 任务失败。

**文献锚点**：
- SGR 1806-20 (2004年巨耀斑): 峰值光度 ~10⁴⁷ erg/s，持续 0.2s
- SGR J1935+2154 (2020): 与 FRB 200428 成协，慧眼 HXMT 探测
- LEO 550km 轨道: 地影约 32 min / 96 min 周期 ≈ 33%

## 任务流

```
磁星爆发 → 探测星 TG-02 触发
    ↓
    产出事件数据包 (2 MB)
    ↓
    通过 ISL 上传计算星
    ↓
    分类推理 (1 s)
    ↓
    结果回传: "SGR confirmed, p=0.97"
    ↓
    触发全星座高灵敏度模式
```

## 能耗约束设计

```
计算星状态设计（10 颗计算星）：
- 4 颗：刚出地影，电量 35%，正在恢复充电
- 3 颗：光照中，电量 70%+
- 3 颗：即将进入地影，电量 55%

阈值：
- LOW_POWER: 30% (拒绝新计算任务)
- SAFE_MODE: 20% (关闭所有非必要设备)
- 磁滞恢复: LOW_POWER → FULL 需 > 33%

关键计算：
- 计算星功耗 (地影中): base 2W + heater 1W + 推理 15W = 18W
- 电池 300 Wh, 35% = 378 kJ
- 18W × 1s = 18 J (看似安全)
- 但如果同时还有通信 (5W): 23W → 若持续 30s 则消耗 690 J
- 问题: 35% 的星能否承受"通信+推理"复合负载？
```

## Baseline 对比预期

| 指标 | 静态拓扑 Baseline | SatLynk (Energy-Aware) |
|------|------------------|----------------------|
| 成功率 | 100% (不建模能耗) | 60-80% (低电量星失败) |
| 失败原因 | 无 | LOW_POWER 模式拒绝 |
| Nearest-First 成功率 | — | ~60% (选了近但电量低的星) |
| Energy-Aware 成功率 | — | ~100% (跳过低电量星) |
| 能耗差异 | 不可见 | 精确到 J 级别 |

## 验证目标

1. C5 能量约束不是装饰性的 — 在实际操作条件下它会 kill 任务
2. Nearest-First vs Energy-Aware Scheduler 的成功率差距
3. 静态模型的"盲区"：看不到能耗导致的任务失败 → 高估系统能力
4. 地影周期与任务到达的耦合效应
